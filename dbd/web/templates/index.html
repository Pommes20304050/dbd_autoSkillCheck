About
Open-source · Flask UI for Manuteaa/dbd_autoSkillCheck

Drop-in Flask UI for Manuteaa/dbd_autoSkillCheck. The default Gradio app (app.py) is untouched — run python app_flask.py for this UI instead.

Hardware-adaptive CPU presets, hybrid-CPU P-Cores pinning, GPU performance monitor (NVIDIA only via nvidia-smi), and a live FPS advisor that compares the rolling tool FPS to the game's FrameRateLimit.

CPU temperature / power readings require LibreHardwareMonitor to be installed and running (its WMI namespace is queried).

Open-source · drop-in alternative to app.py (Gradio). Source: github.com/Manuteaa/dbd_autoSkillCheck
